Cara Instalasi Web
Buka Folder Proyek
Buka terminal/PowerShell, lalu masuk ke folder proyek:

Bash
cd C:\code\Webdes
Instal Dependensi
Unduh paket Tailwind CSS yang diperlukan:

Bash
npm install
Jalankan Tailwind Compiler
Aktifkan mode pemantauan (watch) agar CSS otomatis ter-update:

Bash
npm run dev
Buka Website
Klik ganda file index.html di File Explorer, atau jalankan via ekstensi Live Server di VS Code.
